Parte 3 • Publicación Sin Código en GitHub Pages

Exportar Archivos Actualizados para GitHub Pages

Como GitHub Pages es alojamiento estático, sigue estos tres pasos cada vez que quieras guardar permanentemente tus cambios en el código público sin editar HTML manualmente:

Paso A • Portal Principal

Inyectar configuración en index.html

Selecciona tu archivo index.html actual; esta consola actualizará automáticamente su bloque DEFAULT_CONFIG y descargará el nuevo index.html listo para subir.

Paso B • Consola Admin

Descargar admin.html Actualizado

Descarga una copia limpia de este mismo archivo admin.html con tu nuevo PIN de administrador y valores predeterminados ya guardados.

Paso C • Publicar en la Web

Subir archivos a GitHub Pages

Abre tu repositorio en GitHub, haz clic en Add file → Upload files, arrastra los archivos descargados y pulsa Commit changes.
